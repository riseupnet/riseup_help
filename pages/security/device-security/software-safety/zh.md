# 保持软件更新

几乎每一次攻击者利用软件漏洞攻破电脑，只要软件保持更新，攻击本来都可以被阻止。这是因为几乎所有漏洞都已被软件开发者知晓，并且在攻击者学会利用这些缺陷之前就已经修复了。

保持操作系统更新尤其重要，因为操作系统对设备上发生的一切都拥有特权访问权限。

如何开启自动更新：

* **macOS**：打开 **Apple** 菜单，选择 **系统偏好设置** > **App Store** > **自动检查更新**。
* **Windows**：点击 **开始** 按钮，选择 **设置** > **更新和安全** > **Windows 更新** > **高级选项**，然后在 **选择更新的安装方式** 下选择 **自动（推荐）**。

注意事项：

* 许多更新需要重启设备才能生效，所以要让更新真正提供保护，你需要允许设备在更新后重启。
* 如果你有特定的软件需求，或者组织有定制软件，自动更新可能会打断工作，因为某些系统更新可能与现有软件不兼容。
* 保持软件更新无法防范网络钓鱼或恶意软件攻击，因为这类攻击靠的是诱骗用户做出不安全的行为。

# 使用应用商店

只要有可能，最好从操作系统的官方应用商店安装软件，原因有几个：

* **真实性**：应用商店里的应用由开发者签名，并经过应用商店验证。
* **更新**：应用商店会帮你保持应用更新。
* **防止侧载攻击**：从官方应用商店之外安装应用，叫做“侧载”。Android 目前默认禁用侧载，iOS 完全不允许侧载，而 macOS 和 Windows 默认允许侧载。侧载开启时，你的电脑更容易受到多种恶意软件攻击。因此，macOS 和 Windows 都在尝试转向默认禁用侧载的模式。

注意：使用 Android 官方应用商店 Google Play 时也要小心，那里经常有冒充正版应用的仿冒品。

# 拿不准，就别装

移动应用、浏览器扩展和其他免费（指零成本，不是开源）程序的泛滥，造成了许多安全问题。避免安装那些并非来自你已经信任的公司的软件（也就是说，你的组织已经在使用其工具的公司）。

看起来动机良好（例如杀毒扫描）或功能有用的软件，可能在后台掩盖恶意活动。在大多数浏览器和移动设备上，应用安装时会请求某些权限——也就是它能访问你设备上的哪些信息和硬件。这些权限值得看一看，至少确认它们大致符合预期。例如，如果一个手电筒应用请求访问你的联系人或拨打电话的权限，你大概就不该安装它。授予权限时要特别小心这几类：通话、联系人、摄像头、麦克风、定位服务，以及整个存储空间。

安装后如何查看权限，取决于具体环境。在 Chrome 中，打开 `chrome://extensions/`，逐个点击权限链接。在 iOS 设备上，“设置”里有所有权限的列表，每个权限下面列出了使用它的应用。在 Android 设备上，打开“设置” > “应用管理”查看应用列表，每个应用下面列出了它使用的权限。

不幸的是，笔记本电脑和台式机上的大多数软件安装系统不会询问资源访问权限，所以对于不是来自移动应用商店、浏览器商店或操作系统应用商店的软件，安装时要格外小心。

# 使用盗版软件时要小心

为了免费运行，盗版软件通常会修改原版（付费）软件的源代码。它们还经常附带额外文件——破解文件——用来绕过原软件的许可证验证。虽然有时这无害，但大多数时候，我们无法简单判断修改过的代码和额外文件里是否含有某种恶意软件，会感染并破坏我们的电脑。

此外，如果你在工作电脑上安装盗版软件，你的公司很可能要为你这一台设备支付数千美元罚款。发生这种情况时，你可能因为违反雇主的安全和隐私政策而被解雇。

如果你必须使用某个应用，又不想通过安全渠道获取，可以考虑使用自由及开源软件的替代品。

如果你没有别的选择，必须使用盗版软件，请**格外小心**，并尽量用你信任的杀毒软件或恶意软件扫描器扫描这些软件文件。

# 使用自由软件

下面这些自由及开源应用是常用商业软件的良好替代品，可用于 Mac、Windows 和 Linux：

* **[Gimp](https://www.gimp.org/)**：位图图像和照片编辑程序（替代 Adobe Photoshop）
* **[Inkscape](https://inkscape.org/en/)**：矢量绘图程序（替代 Adobe Illustrator）
* **[LibreOffice](https://www.libreoffice.org/)**：办公套件（替代 Microsoft Office）
* **[Scribus](https://www.scribus.net)**：桌面出版应用（替代 Adobe InDesign）
