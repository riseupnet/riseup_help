# 哪种移动设备最适合我？

理想的移动设备取决于你的处境：

- **高风险**：你怀疑自己可能成为政府或专业监控公司的目标。
- **中等风险**：你没有被主动针对，但希望设备在攻击者拿到手时不容易被攻破。
- **低风险**：你不使用移动设备处理敏感信息。

## 高风险

如果你属于高风险用户，**不要用手机处理任何敏感事务**。原因是所有手机都有一个“基带调制解调器”，用来连接无线电话网络（“蜂窝数据”）。这些调制解调器是专有的，充满可被远程利用的安全漏洞。一旦被攻破，基带调制解调器就可能被用来监控你的通信并提取你的个人数据。

作为手机的替代品，你可以购买只支持 Wi-Fi、无法连接无线电话网络的平板电脑。这类设备没有基带调制解调器，远程攻击难度大得多。使用仅支持 Wi-Fi 的设备时，你仍然可以通过另购一个“移动热点”来连接无线电话网络。

注意：飞行模式还不够。取决于设备型号，飞行模式可能仍然会给基带调制解调器供电，让它继续暴露在攻击之下。

推荐的仅 Wi-Fi 设备包括：

- Google 的 [[Pixel C => https://en.wikipedia.org/wiki/Pixel_C]] 或 [[Pixelbook => https://en.wikipedia.org/wiki/Google_Pixelbook]]。
- Apple 的 [[iPad => https://en.wikipedia.org/wiki/IPad]]，但仅限于**不支持蜂窝数据**的型号。

## 中等风险

你的移动设备里有没有一些敏感信息，是你真的不希望被犯罪分子、政府或爱窥探的同伴偷走的？当然有，每个人都有。

在这种情况下，你希望别人捡到或偷走你的设备时，很难攻进去。

很遗憾，你最好的选择是购买 Google 或 Apple 生产的设备。这些设备的硬件安全性比其他厂商好得多，系统更新也更及时。不过，即使这些设备，只要攻击者足够老练，或者设备处于解锁状态，通常还是能被攻破。

推荐的设备包括：

- Google 的 [[Pixel => https://en.wikipedia.org/wiki/Google_Pixel]]
- Apple 的 [[iPhone 或 iPad => https://en.wikipedia.org/wiki/IPhone]]（需要 iPhone 4S 或更新机型，才能受益于设备加密）

## 低风险

你是不是经常把手机随手一放，完全不解锁？恭喜你，你已经在接受一个现实：移动硬件的安全性并不高。

不过，如果你遵循本页的其他移动安全建议，对你和你通信的人仍然有很多好处。

# 让设备始终在身边

最好让设备时刻处于你的物理视线内。否则，攻击者有很多方法攻入设备、窃取数据，并安装软件来监控你今后的活动。

你的设备有多容易被攻破，取决于你是否使用“推荐硬件”、是否启用了[[设备加密 => device-encryption]]，以及是否用密码或 PIN 锁定了设备。

攻击者类型：

- **老练的攻击者**包括大型政府和专门破解锁定手机的国际公司。
- **熟练的攻击者**包括地方警察和本地的手机解锁公司。
- **普通攻击者**包括没有专业设备的熟练技术人员。

如果你的设备离开了你的视线，而你怀疑它可能被攻破，应该备份数据并做一次彻底的恢复出厂设置（或者考虑买一台新设备）。

# 使用 Signal

获取 Signal：

<%= render partial: 'signal_android' %> <%= render partial: 'signal_ios' %>

**Signal** 是一款自由软件的即时通讯应用，可以作为手机自带短信的安全替代品。它的用法类似 WhatsApp 或 Telegram，但安全性好得多。

为什么要用 Signal？

- 你的手机运营商会记录你发送的每一条短信。使用 Signal 时，运营商无法获取你的消息内容或通信模式。
- 攻击者相对容易接管你的手机号码。使用 Signal 时，如果有人更换了“安全号码”，你会收到通知提醒。别人换新手机时也会触发这个提醒。
- Signal 还可以用于高度安全的语音通话。你的手机运营商会记录你打给谁、谁打给你，以及每次通话的时长。使用 Signal 时，运营商拿不到这些信息。只要你的设备没有被攻破，通话内容也是保密的。
- 其他“安全”通讯应用，比如 WhatsApp、Telegram 或 Wire，与 Signal 相比都有很多问题。

更多信息见 [[Security Planner / Signal => https://securityplanner.org/#/tool/signal]]。

# 启用“查找我的设备”

考虑启用“查找我的设备”。这样当设备丢失或被盗时，你可以远程定位、锁定或擦除个人信息。

更多信息见：

- [[Security Planner / 查找我的设备（Android）=> https://securityplanner.org/#/tool/find-my-device]]。
   - 注意：这个功能要求你把 Google 账户与设备关联。而且，如果你启用“查找我的设备”，Google 会保留更多关于你的信息，例如你的位置历史记录。
- [[Security Planner / 查找我的 iPhone（iOS）=> https://securityplanner.org/#/tool/find-my-iphone]]

# 安全地拍照

手机摄像头会在你拍摄的每张照片里嵌入大量潜在的敏感信息。你永远不知道发到网上的东西会被人怎么利用，所以分享照片前，最好始终清除其中的个人信息。

要防止照片被“地理位置标记”，请打开相机应用的设置，找到关闭“在照片中保存位置数据”的选项。

即使关闭了地理位置标记，相机应用仍会保存设备型号和其他潜在敏感信息。要想彻底去掉这些信息，只能使用单独的应用程序删除图像文件中的“EXIF”数据。这类应用也可以用来清除你过去拍摄的照片中的位置数据。

更多信息见：[[从照片中移除 EXIF 元数据的 3 种方法 => https://www.makeuseof.com/tag/3-ways-to-remove-exif-metadata-from-photos-and-why-you-might-want-to/]]。

# 其他建议

- 用密码短语，至少用 PIN 码来解锁手机。不要使用手机的指纹或人脸解锁功能，这些功能并不安全。
- 配置手机，不要在锁屏上显示详细通知。
- 了解你的手机会与云端同步什么。例如，即使你从手机里删除了一张照片，它可能早已备份到 iCloud 或 Dropbox 等一个或多个云服务中。
