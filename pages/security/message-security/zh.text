@title = "消息安全"

*消息安全*是指在你自己的设备上加密消息，让只有预期的收件人才能读取。虽然[[网络安全 => network-security]]和[[设备安全 => device-security]]很重要，但在很多情况下，这种*消息加密*是必需的：

* *保密性*：要确保只有预期的收件人读到你的消息，消息加密是唯一的方法。
* *真实性*：要确认和你通信的人的身份，消息加密是唯一的方法。

不过，实践消息加密并不容易：

* *你必须拥有自己的设备*：消息加密的前提是，你不信任第三方替你加密通信。因此，所有加密都在你自己的机器上完成，这意味着你需要拥有自己的设备。
* *学习曲线陡峭*：要正确使用加密软件，你需要花不少时间学习公钥、私钥、密钥环等重要概念。
* *通信对象有限*：使用消息加密时，你只能和其他使用相同软件的人安全通信。

显然，如果你的设备已经被攻破，这些安全保证就不成立了。

h1. 关于消息加密

这些帮助页面所说的“消息加密”，在技术上叫“公钥密码学”。它的工作原理如下：

* *私钥*：每个人都有自己的私钥。顾名思义，私钥必须保密。你用私钥读取别人发给你的加密消息。
* *公钥*：每个人也有一把公钥。公钥通常会被广泛分发。当别人想给你发送安全消息时，会用你的公钥加密。只有拥有对应私钥的人才能解密。

*学习消息加密的提示*

公钥加密虽然提供了最高级别的安全，但用起来仍然像一场冒险。为了让这段旅程不那么吓人，我们建议你记住几点：

* *做好长期投入的准备*：使用公钥加密需要你下决心学习大量新技能和术语。公钥加密的普及还遥遥无期，所以看起来可能付出很多、收益不大。但是，我们需要早期采用者，帮助形成公钥加密用户的临界规模。

* *结交加密伙伴*：虽然你的大部分通信可能没有加密，但如果你找到另一个使用公钥加密的人，可以试着养成只和对方安全通信的习惯。

* *寻找倡导者*：使用公钥加密的人通常很喜欢宣传它，也乐于帮助别人使用。找一个这样的人，让他回答你的问题，带你上手。

*消息加密的局限*

虽然公钥加密可以隐藏邮件内容，但它*不能*隐藏你把邮件发给了谁、又从谁那里收到邮件。这意味着，即使使用了公钥加密，仍有很多个人信息是不安全的。

为什么？想象一下，有人完全不知道你邮件的内容，但知道你给谁发邮件、从谁那里收邮件，也知道你们通信的频率和邮件主题。这些信息足以勾勒出你的社会关系、习惯、联系人、兴趣和活动。

要让你的联系人列表保持私密，唯一的办法是使用一家能与其他服务提供商建立安全连接的服务商。参见我们的[[激进服务器目录 => radical-servers]]，那里列出了这类服务商。
