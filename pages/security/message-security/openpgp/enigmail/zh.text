@title = '使用 Thunderbird 加密电子邮件'

想学习如何在 [[Thunderbird => email/clients/thunderbird]] 中使用 OpenPGP，来提升邮件安全性吗？这份简短的入门指南可以让你很快上手，学会加密和解密邮件，并验证收到的邮件确实来自你预期的发件人。

h2. 开始之前

我们建议你先阅读我们的 [[GPG 最佳实践 => gpg-best-practices]]指南。尤其要确保：*在生成密钥之前*，你已经按照 [[GPG 最佳实践 => gpg-best-practices]] 配置好 GPG 客户端，以便生成强密钥，因为默认安装的设置并不理想。

如果你已经有密钥，继续之前应该[[运行这些检查，确认密钥足够强 => gpg-best-practices#openpgp-key-checks]]。

h2. 安装 Enigmail 并运行 OpenPGP 设置向导

Enigmail 是一个 Thunderbird 扩展，让你可以在邮件中使用 OpenPGP 加密。

# （可选）你可以让 Enigmail 替你生成密钥对，也可以[[手动生成 OpenPGP 密钥对 => /security/gpg-keys]]。
# 下载“Enigmail”：https://www.enigmail.net。**Linux 用户**——最好下载并安装这个扩展，以获得最新版本，而不要使用包管理器提供的版本，那很可能已经过时。以后 Thunderbird 会自动安装 Enigmail 的更新。
# 打开 **工具** -> **附加组件**
# 点击 **安装...** 按钮
# 找到 Enigmail 的 .xpi 文件，选择 **打开**。Enigmail 就会开始安装。
# 如有必要，重启 Thunderbird
# 打开顶部菜单中新出现的 **OpenPGP** -> **设置向导**
# 选择 **是**，然后点击 **下一步**
# 如果你在 Thunderbird 里创建了多个身份，选择是为所有身份还是只为部分身份设置 OpenPGP。如果有多个身份，选择为所有身份设置 OpenPGP 会让它们共用一把密钥。
# 选择是否要给你所有的外发邮件签名。**签名不会加密邮件**——它只是把数字签名附加到你**所有**外发邮件上，让别人能验证邮件是你发的。建议**不要给所有外发邮件都签名**，因为这会把你和你通过未加密邮件直接发出的一切内容强关联起来。最好的做法是：只给你认识、且支持加密的人发加密邮件。
# 选择是否默认加密所有外发邮件。**不建议这样做**，因为如果收件人不支持加密，会很不方便。你可以稍后设置加密规则，在你自己确定的条件下自动发送加密邮件。
# 选择接受 OpenPGP 推荐的一些更改。这些都是 Thunderbird 里的技术配置更改，可以简化 OpenPGP 流程，避免导致故障的配置。这些更改都是安全的，不过有些会改变功能，最明显的是会禁用撰写 HTML 邮件。
# 如果你还没有密钥，就创建一把；否则选择一把现有密钥。如果你有多把密钥和/或多个身份，稍后可能需要手动调整，把正确的密钥关联到正确的身份。
# 检查建议的更改，然后点击 **下一步**
# 如果没有错误，OpenPGP 就可以使用了。点击 **完成**。

h2. 设置 OpenPGP 规则

在 Thunderbird 中，Enigmail 扩展允许你设置规则，让 Thunderbird 自动决定谁会收到你的加密邮件、谁不会。

这套规则系统相当强大，可以组合出很多选项。本指南会创建一条规则，始终向某个特定邮箱地址（或多个地址）发送加密邮件，并假设你的邮件默认不加密。不过，这套规则系统似乎足够强大：如果你的大多数联系人都使用 OpenPGP 加密，你可以默认加密，再创建一条规则，向不支持加密的联系人发送未加密邮件。

# 打开 **OpenPGP** -> **编辑按收件人规则**
# 点击右上角的 **添加** 按钮。
# 在顶部输入邮箱地址；如果要匹配多个地址，用空格分隔。如果要精确匹配地址，选择 **完全一致**；也可以输入匹配词并选择合适的匹配方式。可用的匹配方式有：**完全一致**、**包含**、**开头是**、**结尾是**。
# 选择匹配规则后要执行的 **操作**。在这个例子里，选择 **使用以下 OpenPGP 密钥：**，然后点击 **选择密钥...** 按钮。在弹出的框里，选择你要发送对象的 OpenPGP 密钥。如果你没有对方的公钥，点击 **下载缺失的密钥** 按钮，它会用你在匹配框里输入的邮箱地址去密钥服务器搜索。
# 在 **...的默认设置** 区域，把 **加密** 改成 **始终**，签名和 PGP/MIME 保留 **是，如果在撰写邮件时已选择**。
# 规则配置完成后，点击 **确定**。!/security/message-security/openpgp/enigmail/enigmail-create-rule.gif!

现在，你可以通过 Thunderbird 向任何收件人发送 OpenPGP（GPG）邮件，并且对你刚创建的规则中指定的收件人自动启用加密了。
