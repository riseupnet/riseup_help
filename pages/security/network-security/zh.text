h2. 提升你的网络安全

互联网是个狂野的地方。你几乎每一次点击，都会被某处的电脑记录、归档和分析，用来预测你的消费行为，或者执行民族国家的法律。你把电脑接入互联网的那一刻，病毒和破解者就可能来探测漏洞，想把它征召进“僵尸网络大军”：https://en.wikipedia.org/wiki/Zombie_computer。

可怕吧！普通互联网用户该怎么办？这些页面会帮你配置电脑，在[_网络层面_]阻止这些攻击。
