@title = '激进服务器'


这里列出了一些反资本主义、反等级制、自治、女性主义或激进的服务器项目。
其中一些是革命性的集体，为激进和草根行动者提供免费或互助服务。
另一些更侧重隐私或去中心化。
它们都不以赚钱为目的。
Riseup 并不为这些项目背书，只是保留一份列表，供大家自行选择！
请仔细阅读各项目的服务条款，因为其中一些可能受执法或监控法律约束。

想更新你们集体的信息，或者想被列在这里？[[编辑我们的仓库 => https://github.com/riseupnet/riseup_help]]。

h1. 全球

h2. hackerspaces.org

[[Hackerspaces => https://wiki.hackerspaces.org]]是社区运营的实体空间，人们可以在这里见面、做项目。这个网站面向任何想与全球黑客空间社区分享故事和问题的人。

h2. hackthissite.org

[[HackThisSite.org => https://www.hackthissite.org]]是一个免费、安全且合法的训练场，黑客可以通过挑战、CTF 等方式测试和拓展自己的道德黑客技能。我们从 2003 年活跃至今，不只是一个黑客战争游戏网站。我们是一个活生生的社区，致力于学习和分享道德黑客知识、技术爱好和编程经验，许多项目正在开发中。欢迎加入我们的 IRC、Discord 和论坛，用户可以在那里讨论黑客技术、网络安全等。来接触黑客地下世界，参与这个项目吧！

h2. indymedia.org

[[indymedia.org => https://www.indymedia.org]]是一个去中心化的全球媒体行动者网络。

* 新闻源

h2. tachanka.org

[[Tachanka => https://tachanka.org]]的理念是为解放性项目和政治变革团体提供技术服务。它也是提出这个理念的一群人。有许多相互重叠的集体帮助维护项目，但 Tachanka 遵循许多共同原则，形成一个支持性网络，以实现共同目标。这些集体是国际性的，力求加强全球团结。Tachanka 项目的首要指导原则是[[人民全球行动的特征 => https://en.wikipedia.org/wiki/Peoples%27_Global_Action#Hallmarks]]和[[Debian 社会契约 => https://www.debian.org/social_contract]]。

* 邮件列表
* 虚拟服务器
* DNS 缓存
* Drupal 农场
* 英语 / 法语 / 葡萄牙语

h2. Take Back The Tech!

[[Take Back The Tech! => https://www.takebackthetech.net]]是一项全球运动，把针对女性的暴力与信息通信技术（ICT）联系起来。它旨在提高人们对互联网和手机等 ICT 平台上针对女性的暴力的认识，并呼吁人们利用 ICT 参与行动，终结针对女性的暴力。该运动由[[进步通信协会 => https://en.wikipedia.org/wiki/Association_for_Progressive_Communications]]（[[apc.org => https://www.apc.org]]）的妇女网络支持计划于 2006 年发起。此后，至少 24 个国家的个人、集体和非政府组织参与并组织了这项运动。更多信息见[[维基百科 => https://en.wikipedia.org/wiki/Take_Back_The_Tech!]]。

h2. 电信中心

[[电信中心（Telecentre）=> https://en.wikipedia.org/wiki/Telecentre]]是一种被广泛采用的概念：在配有电脑和其他数字技术的公共场所，提供免费互联网接入和其他服务，让人们能够获取信息、创造、学习、与他人交流，同时培养基本的数字技能。[[电信中心网络管理指南 => https://en.wikibooks.org/wiki/A_Guidebook_for_Managing_Telecentre_Networks]]

* 决策 ≻ Framavox（Loomio）
* 类似 Pocket ≻ Framabag（Wallabag）
* 类似 Google Reader ≻ Framanews

* 类似 WeTransfer ≻ Framadrop

还计划提供 Change/Avaaz、Google Calendar、Google Groups、Blogger、Wix 等的替代品。

参见[[这个页面查看所有服务 => https://degooglisons-internet.org/liste?l=en]]并访问它们（主页是法语，但大多数服务有多种语言版本）。

h2. Taharar!

[[Taharar! => http://www.taharar.org]]（阿拉伯语“解放你自己！”）是一个自治项目，旨在为西亚和北非从事社会正义议题的个人、集体和团体赋权，为他们提供替代性的通信和技术服务、信息、资源和支持。Taharar! 的愿景是：通过提供本地语言（包括阿拉伯语、波斯语、希伯来语、库尔德语等）的无障碍资源池，让人们能够通过使用和推广自由开源软件与技术，掌控自己的安全通信手段，创造民主替代方案，从而对抗西亚和北非盛行的数字审查。

h2. Gleducar

[[Gleducar => http://www.gleducar.org.ar]]是一个 2002 年在阿根廷出现的自由教育项目。它也是阿根廷教育和技术领域重要的非政府组织（民间协会）。它是一个独立社区，由教师、学生和教育行动者组成，因对集体工作、合作式知识建构和知识自由分发的共同兴趣而联系在一起。项目围绕开放教育、开放获取、自由知识、大众教育、同伴教育、协作学习和自由技术等主题展开。他们推动在学校使用自由软件作为教学和技术系统，目标是改变教育内容的生产、构建和传播范式。[[维基百科 => https://en.wikipedia.org/wiki/Gleducar]]

* 自由开放的数字化教育

h2. GuardaChuva.org

[[GuardaChuva.org => http://GuardaChuva.org]]研究小组是一个跨学科空间，诞生于 2005 年中期，目标是推动关于信息社会、网络空间和技术的研究。为此，研究小组进入技术—科学—信息环境，利用自身知识托管网页、Wiki、图书馆编目，以及不同网络行动者团体的独立自治项目。

h2. Saravá

[[Saravá => https://www.sarava.org]]是一个多学科集体，目标是优化社会团体对技术的使用，始终关注人机关系中人的一面。我们的研究包括让目标各异的小团体共享同一套物理设施，从而整合并节省技术资源。
