# 使用密码管理器

使用密码管理器，是提升个人安全最重要的改变之一。

密码管理器可以让你使用既强壮又唯一的密码。有了密码管理器，你只需要记住一个密码来打开它的安全文件或账户，其余所有密码都由它保存。

密码管理器有三个重要特点，你需要了解：

* **本地应用**：一个专用程序，把密码加密后保存在你的电脑本地，用主密码解锁。这是最安全的选择，但在多台设备之间同步密码会比较麻烦。
* **云服务**：一种通常付费的服务，替你保存密码，任何设备都能访问。好处是走到哪里都能用，代价是安全性略低。
* **浏览器插件**：应用型和云服务型密码管理器通常都提供浏览器插件，让你在浏览器里随手调用密码。这很方便，但安全性会略低一些。

不管你选哪一种，真正重要的是：你要用密码管理器。请记住两个要点：

* **主密码**：使用密码管理器时，千万不要弄丢“主密码”。如果你觉得自己有可能忘记，就把它写下来。
* **备份**：定期备份密码管理器的数据也非常重要。云服务会替你备份，但最好偶尔也做一份本地备份。对本地应用来说，备份它的数据文件就够了。

常见的密码管理器包括：

* KeePass 和 KeePassX（应用型）：一个广受推荐的本地密码管理器的两个版本。这两个工具使用相同的加密文件格式，几乎可以在任何电脑上运行。
   * [《监视自卫指南》/ 如何使用 KeePassXC](https://ssd.eff.org/en/module/how-use-keepassxc)
   * [Security In-a-box / KeePass 概览](https://securityinabox.org/en/guide/keepass/windows)
* LastPass（云服务型）
* 1Password（云服务型与应用型）

# 使用强密码

强密码是*随机生成*的。除了解锁设备的密码和解锁密码管理器的主密码之外，你所有的密码都应该由密码管理器随机生成，长度至少 12 个字符，但不需要超过 26 个字符。

人类很不擅长想安全密码，电脑却很擅长。让电脑替你想。

对于那些你必须记住的密码，有很多生成强密码的方法；如果你在使用密码管理器，就让它替你生成。《监视自卫指南》里有一篇[创建强密码](https://ssd.eff.org/en/module/creating-strong-passwords)的指南。

[Diceware](https://world.std.com/~reinhold/diceware.html) 是一种有趣而有效的方法：用日常物品和词表生成随机但容易记住的密码。另一个生成强密码的好办法，是想一句以前没人说过的傻话，取每个词的开头一两个字母作为密码，再混入其他类型的字符。

对所有账户都使用强密码很重要，因为攻破一个账户，往往就能借它进入其他系统。这一点对任何能用来重置或找回其他密码的邮箱账户尤其重要（通常是通过“忘记密码”链接）。

# 使用唯一密码

这是降低使用第三方技术服务风险的好办法。如果你不重复使用密码，那么即使有人通过数据泄露或入侵知道了你在某个服务的用户名和密码，也无法轻易进入你使用的其他账户。为每个服务使用不同的密码，这样你就不必依赖你登录的服务来保护你最重要的秘密。如果你使用密码管理器，这件事很容易做到。

# 保守密码的秘密

即使有人自称来自 IT 或技术支持部门，也不要把你的密码交给他们。几乎所有系统都允许管理员在维护时重置密码。任何正当的 IT 人员都可以使用这个功能，而不必向你要密码。这个机制还会留下可审计的账户访问记录，并在密码被重置时提醒你。管理员访问之后，你需要再次修改密码；但多走这一步，能确保只有你本人能访问你的数字信息，也能让你知道组织里谁对你的账户做了什么改动。

# 把组织密码和个人密码分开

组织密码包括任何能授予组织信息系统或在线身份管理权限的密码。这些凭证权力很大，应该与普通员工登录个人账户的密码分开保存。你可以在密码管理器里为它们建立单独的安全文件或登录项，也可以干脆另选一个完全不同的密码管理器。
