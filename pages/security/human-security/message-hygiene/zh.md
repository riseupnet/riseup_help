# 永远不要相信发件人

电子邮件之所以成为组织里大多数攻击的来源，首要原因是：我们无法验证“发件人”地址的真实身份。

再说一遍：任何人都可以伪造“发件人”地址，让任何一封邮件看起来像是另一个人发来的。

由于很难验证发件人，你的收件箱就成了**网络钓鱼攻击**和**恶意软件攻击**的常见入口。

* **网络钓鱼攻击**：有人冒充某个机构或个人发来邮件，利用这种欺骗获取信息。他们可能想要社保号码、银行信息、密码或其他敏感信息。
* **恶意软件攻击**：攻击者诱导你打开附件或点击链接，从而在你的电脑上安装恶意软件。

一般来说，收件箱里任何意料之外的内容都应该被怀疑。对任何要求你做某件事的消息都要保持警惕，包括点击链接、打开附件或回信提供信息——即使它们来自你认识的人！

如果有人入侵了你的账户，你可能会看到自己无法理解的回复、额外的已发送邮件、新建的文件夹或过滤器，或者设置上的其他变化。遇到可疑邮件或账户行为，应该向技术支持人员报告，并主动修改密码。

# 避免点击邮件里的链接

链接——通常看起来无害，甚至隐藏在邮件文字里——是攻击者窃取你的数据、控制你的设备的主要手段。

最好的做法是：永远不要点击邮件里的链接。如果你确实需要点击，请按下面的清单检查：

* 你预期会收到这封邮件吗？即使“发件人”地址看起来属于你认识的人，收到意料之外的邮件时也要非常谨慎。
* 你能不能手动输入链接，而不是直接点击？你在邮件里看到的链接，可能并不是它真正指向的地址。域名可能包含“同形异义字符”，也就是看起来相同、实际不同的字符（例如数字“0”和大写字母“O”，或者拉丁字母与西里尔字母）。看起来是 <https://riseup.net> 的链接，实际可能指向攻击者的网站 <%= '<a href="https://riseuρ.net">https://riseuρ.net</a>' %>（第二个链接用希腊字母 ρ 代替了字母 p）。对用户来说，避免这种攻击最安全的方法是：永远不要从不可信的来源复制 URL，而要把 URL 直接输入地址栏。
* 你认识这个域名吗？在大多数邮件程序和网页里，把鼠标悬停在链接上会显示它指向的 URL。如果链接的目标出乎意料或你不熟悉，先向发件人核实这封邮件是否真实。链接应该始终以“https://”开头。如果它以“data://”开头，那一定是网络钓鱼攻击。

永远不要点击陌生发件人的链接，也不要打开可疑邮件里的文件。与你认识并合作的伙伴不同，陌生人不会发来你真正需要的文件；如果陌生发件人的链接里确实有有用信息，你总可以通过另一种更可信的方式获取（例如自行搜索）。

# 点击链接后，永远不要登录

如果你确实点击了邮件里的链接，千万不要在打开的网站上登录。如果网站要求你登录，请改按下面的步骤操作：

1. 在浏览器里打开一个新标签页，手动输入该网站的域名。
2. 在这个新标签页里登录网站。
3. 回到邮件，再次点击那个链接。
4. 这次链接打开时，不应该要求你登录。如果它仍然要求登录，这封邮件很可能是网络钓鱼攻击。

这个习惯可以帮你防住大多数网络钓鱼攻击。

# 避免使用附件

邮件附件会带来多种风险，其中之一就是被用于网络钓鱼。附件在发件人和收件人之间可能被查看或篡改，因此你无法保证对方收到的文件就是你发出的那一份。在你和发件人之间的恶意服务器，可以把附件替换成任何程序或文件，包括病毒或恶意软件。此外，附件往往会长期留在收件人的收件箱里，更难控制。例如，如果你用组织的信用卡填写了一份订单，把它做成 PDF 发给供应商，那么任何入侵该供应商邮箱的人，只要这份文件还没从服务器上删除，就能看到你的信用卡信息。

比邮件附件更好的做法是：把文件放在服务器上，发送文档链接，而不是发送文档本身。理想情况下，这些链接指向的位置本身受密码或其他身份验证保护，或者是临时的、使用后很快失效。几乎所有文件存储系统都能轻松生成这种链接，无论服务器在办公室（例如 Windows 文件服务器）还是在网上（例如 Google Drive、Box 或 Dropbox）。
